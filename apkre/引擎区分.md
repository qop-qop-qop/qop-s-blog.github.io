# Unity案例（汤姆猫跑酷）

unity的主要逻辑在libil2cpp.so里面，里面成千上万的函数根本不可能一一看完，所以要还原符号表进行分析。

**Il2CppDumper**就是转变用来产出所有类/方法/字段的命名和偏移

喂入 `libil2cpp.so` + `global-metadata.dat`，产出 `dump.cs`

dump.cs就是所有类/方法/字段的命名和偏移的文件。

游戏共6层

```
┌ L1  Java/Kotlin 层     classes.dex ×3
│     入口 Activity、YSDK 登录支付、Bugly、okhttp、广告 SDK(穿山甲/优量汇/快手)
│     工具：jadx ← 你之前看的只是这层
├ L2  JNI 桥接层（薄）
│     AndroidPluginManager(C#侧) ↔ Java 侧桥接；libmain.so(仅12K, 引导加载 libunity)
├ L3  Unity 引擎层       libunity.so (C++)
│     Unity 2020.3.16f1 本体：渲染/物理/场景/资源
├ L4  IL2CPP 脚本层      libil2cpp.so  ← IDA 主战场
│     全部 C# 编译产物：Outfit7 框架 + 游戏逻辑 + 广告管理(TtgrAdManager)
├ L5  原生 SDK / 安全层   各独立 .so
│     libsgcore(阿里聚安全)、libhadeslib、libgradishwrapper、
│     libpangleflipped(穿山甲)、lib39285EFA(隐藏dex加载器)
└ L6  数据资源层         assets/bin/Data + res/
      场景 level0~19+、预制体、贴图、配置表
      工具：AssetStudio / UABE
```

## 金币，钻石等货币逻辑

提取完符号表在ida里面还原之后发现libil2cpp.so里面Credit/Debit/CanDebit这些C#编译之后的产物承载着所有货币的加减

而所有的加减变化最终都会收敛到

```
CurrencyManager.CreditBalance(account, amount)   @0xC034D0
```

通过hook可以进行返回值的修改。
