# 前言

C++的反编译中很多函数都因为反编译变得晦涩难懂，这时候就可以利用插件HexRays-CppFormatter进行优化。

而输入输出这个插件没有办法很好的优化，被解构出来的流函数还是在。但是其实问题不大，剩下的一点还是能慢慢看懂的。

# 输出

在c++的反编译中 >>跟<<控制流都被反编译成了最原始字节表示，并且有了将流赋值给变量的用法。

```
cout >> #表示输出
```

但是在反编译中

```
std::operator<<<std::char_traits<char>>(&std::cout, "size:");
```

像上面的示例输出即为size:

很明显看到这里的字符串输出被解构为了

```
std::operator<<<std::char_traits<char>>
```

这里再进行一次解构

- `std::` —— 命名空间
- `operator<<` —— 函数名（重载的运算符）
- `<std::char_traits<char>>` —— 模板参数列表

这里其实主要注意的就是模板参数列表，它代表着我这里的输出格式。

**而`operator` 之前的部分**：决定“在哪个命名空间/哪个类里找这个运算符重载”，也就是决定调用哪个具体函数。
